# Luban Excel Merge 用户手册

## 适用范围

Luban Excel Merge 用于解决 Git 或 Fork 中 Luban `.xlsx` 工作簿的三方合并冲突。工具读取 BASE、LOCAL、REMOTE，并将确认后的结果原子保存到 MERGED。

正式发布版本：`1.1.0`。支持 Windows x64，公式重算优先使用 WPS 表格，无法使用时回退到 Microsoft Excel。

## 在 Fork 中使用

1. 在 Fork 中执行 merge 或 rebase。
2. 对冲突的 `.xlsx` 文件运行 Luban Excel Merge。
3. 等待 BASE、LOCAL、REMOTE 分析完成。
4. 逐项解决所有冲突和元数据复核项。
5. 检查 MERGED 表格后点击保存。
6. 保存成功后，工具将当前 MERGED 标记为 resolved 并加入 staged。

仓库级配置、四文件参数和错误排查参见 [Fork / Git 集成指南](Fork-Git-Integration.zh-CN.md)。

## 表格颜色

- 红色：存在冲突，必须选择 BASE、LOCAL 或 REMOTE。
- 黄色：记录或内容被删除。
- 绿色：新增记录或内容。
- 浅蓝色：可自动合并的修改。
- 橙色：Luban 元数据发生变化，需要重点复核。

## 冲突处理

- 点击单元格可处理单个冲突。
- 点击行号可选择该行包含的全部冲突。
- 点击列头可选择该列包含的全部冲突。
- 使用“接受 BASE”“接受 LOCAL”“接受 REMOTE”批量应用选择。
- 使用上一处、下一处跨工作表浏览冲突。
- 使用撤销和重做修正批量选择。

MERGED 区域会即时显示当前选择对应的最终结果。任何工作表仍有未解决冲突时，整本工作簿都不能保存。

## 自动编辑浏览

当状态栏显示工作簿已经自动编辑且可以直接保存时，点击左下角状态文字即可定位自动编辑内容。

- 第一次点击定位第 1 处自动编辑。
- 重复点击依次浏览后续自动编辑。
- 可自动跨工作表切换。
- 到达最后一处后继续点击会回到第 1 处。
- BASE、LOCAL、REMOTE、MERGED 四张表始终同步定位。

## 多工作表

顶部标签用于切换工作表，并显示每个工作表剩余的冲突数量。BASE、LOCAL、REMOTE 的工作表名称、数量和顺序必须一致。

每个工作表独立分析，但保存以整个工作簿为单位。所有工作表的冲突和元数据复核项都完成后才能保存。

## Luban 元数据复核

不改变既有字段布局的元数据内容变化会以橙色高亮进入复核流程。用户必须明确选择 BASE、LOCAL 或 REMOTE。

工具支持 LOCAL 或 REMOTE 在任意位置新增字段列：

- 单侧新增字段会作为自动编辑写入 MERGED，并可通过左下角自动编辑提示逐处查看。
- MERGED 以 LOCAL 的字段布局为基准；LOCAL、REMOTE 分别新增不同字段时保留双方字段，列位碰撞的远端字段移动到首个安全空列。
- 两侧新增同名字段但数据不同会进入内容冲突；类型或元数据不同会进入橙色元数据复核。
- 新字段数据按主键对齐，远端新增记录会携带完整新字段值。

删除、重命名、重排或修改既有字段类型仍属于不安全结构，也不支持改变元数据行或数据起始行。REMOTE 独有的新字段如果包含公式且必须移动列位，工具会阻止合并，避免公式引用指向错误列。

## WPS 与公式

默认模式为 `auto`：

- 不影响公式时不会启动办公软件。
- 公式可能受影响时优先调用 WPS 表格完成重算。
- WPS 不可用时尝试 Microsoft Excel。
- 重算失败时不会覆盖已有 MERGED。

选择 `never` 时，工具保留来源缓存并标记下次打开完整重算。保存后应使用 WPS 打开并保存一次以确认公式结果。

## 诊断与性能

日志默认位于 `%LOCALAPPDATA%\LubanExcelMerge\logs\日期`。日志包含三个输入文件读取时间、工作表分析时间和总耗时，但不记录单元格正文。

工具栏中的诊断按钮可导出不包含工作簿的诊断包。大表出现异常等待时，应保留诊断包以及工作簿行数、列数和工作表数量。

## 保存安全

- MERGED 使用临时文件和原子替换写入。
- 写入后会重新打开并验证工作簿。
- 项目校验失败时恢复保存前文件。
- Git 暂存失败时保留已经生成的 MERGED，并显示具体 Git 错误。
- 工具只暂存当前 MERGED，不执行 `git add .`。

## 当前限制

- 合并输入必须为 `.xlsx`。
- 每个参与合并的工作表必须能够解析为平面 Luban 表。
- 三方工作簿的工作表名称、数量和顺序必须一致。
- 多工作表模式暂不与全逻辑表唯一性扫描同时启用。
- 说明页、图表页或层级结构表不参与自动合并。
