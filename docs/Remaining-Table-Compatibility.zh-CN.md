# 普通字段行与辅助页合并规则

## 普通字段行

普通工作表允许前 8 行内出现英文字段行，必须恰好包含一个 Id/id 字段、字段名唯一、三方字段行和物理列布局相同，且所有数据列都有字段名。主键通过三方非空及唯一性检查；不以列 A 或任意首列猜测 Id。原说明行、字段行、列位置及数据起始行不改变。

## 辅助页

无 Luban 字段标记、也不符合普通字段行规则的辅助页，不再因变化而阻断整本工作簿。其内容变化全部按原单元格地址进入橙色复核，包括单边变化；未确认不能保存。不自动识别记录身份、插行、删除或重排；有行列移动时应逐格复核，必要时先统一该页。

辅助页行列布局、纯样式差异、批注和图形保留 LOCAL，GUI 保存前明确确认。选取 BASE/REMOTE 内容时导入该单元格的来源样式。辅助页不清理空白格式占位。命令行直接保存遇到辅助页复核规则时拒绝，要求进入 GUI 确认；不静默忽略该页差异。

## 数字比较和输入诊断

数字单元格去除写入器尾差时采用 15 位有效数字比较，保留精确整数差异，文本、主键编码和公式文本不受影响。只改变比较，不舍入或改写源值。依据：[Microsoft Excel 浮点精度说明](https://learn.microsoft.com/en-us/office/troubleshoot/excel/floating-point-arithmetic-inaccurate-result)。

Git LFS 冲突文本输入给出具体说明：工作区文件尚未成为真正 xlsx，需使用 BASE/LOCAL/REMOTE 完成合并。保留既有 Git LFS 对象解析和缺失对象校验。

## 验证边界

真实样本来自 5 个冲突文件的 Git stages 1/2/3。预检查和试保存均在隔离目录进行，没有更改项目源表或 Git index。回归包含非 A 列 Id、三方表头变化、重复键、辅助页复核/撤销、源值选择、LOCAL 辅助页布局逐字节保留、命令行门禁以及数字尾差与真实数值差异。

155 项回归全部通过，覆盖大、小指数数值差异及非有限数值拒绝比较。5 组真实三方样本全部完成预检查，4 组隔离保存结果通过独立按主键逐字段三方比对、包检查和 Excel 只读打开验证；剩余一组保留删除/修改冲突供使用者选择。未提交真实工作簿或具体业务单元格内容。
